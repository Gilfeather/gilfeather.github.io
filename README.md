# Gilfeather portfolio

A bilingual Japanese / English static portfolio. No runtime dependencies, trackers, or external fonts.

## Edit and preview

Edit the content in `build.mjs`, and the layout in `dist/style.css`. The orange/sky-blue palette and theme-aware styles are in `dist/appearance.css`; theme restoration is in `theme-core.js` and selection handling is in `dist/appearance.js`.

```sh
node build.mjs
node serve.mjs
```

The preview runs at http://127.0.0.1:4173. Publish the contents of `dist/`.

## Appearance and positioning

The default follows the OS light/dark preference. Visitors can choose System, Light or Dark; that choice is kept locally, including across Japanese/English navigation and open tabs. The company website shares the palette, but this site remains a personal portfolio of engineering experience, projects and approach. Development enquiries link to Vaunt; project feedback stays on GitHub.
